# Система управления персоналом компании (HRM System)

Веб-приложение для автоматизации кадрового учета малого предприятия, разработанное в рамках курсовой работы. Архитектура проекта построена по паттерну MTV (Model-Template-View) с использованием реляционной базы данных и системы ролевого доступа.

## Технологический стек
* **Backend:** Python 3, Django 4.x
* **База данных:** SQLite (встроенная)
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Архитектура:** MTV, ORM-моделирование

## Основной функционал
1. **CRUD-операции:** Добавление, чтение, редактирование и удаление профилей сотрудников.
2. **Справочник отделов:** Использование связи "один-ко-многим" (Foreign Key) с защитой от удаления связанных данных.
3. **Валидация данных:** Проверка контактных телефонов (Regex) и email-адресов на стороне сервера.
4. **Ролевой доступ:** Просмотр списка доступен всем, редактирование — только авторизованным HR-менеджерам.
5. **Экспорт данных:** Выгрузка актуального кадрового состава в формат `.csv` для Excel.
